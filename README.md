# kelly-james
## Christmas card (`christmas/`)
An animated Christmas card: a red envelope on a candlelit Christmas table, tap to open, and the photo card rises out.
Personalise it with the card maker (`christmas/maker.html`). The table is decorated with hand-drawn art drawn in code:
a pine branch with baubles, a flickering candle with holly, a wrapped present and pine cones. The envelope has faint
embossed snowflakes and the card has gold corner flourishes.
